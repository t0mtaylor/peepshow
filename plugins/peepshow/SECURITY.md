# Security policy

This directory is the installable plugin surface for peepshow. Reporting,
supported versions, and the full account of what peepshow executes on your
machine live in the repository's [`SECURITY.md`](../../SECURITY.md).

Report privately via
[GitHub security advisories](https://github.com/t0mtaylor/peepshow/security/advisories/new)
rather than opening a public issue.
